# بوابة طلب وثيقة / تأييد — كلية الوركاء الجامعة

نموذج موقع ديناميكي لطلب الوثائق الدراسية والتأييدات لطلاب كلية الوركاء الجامعة
(شعبة الشؤون والتسجيل — قسم اللغة الإنجليزية).

## شنو يسوي الموقع

- **صفحة الطالب:** فورم طلب (الاسم الرباعي، الجنس، نوع الطلب، الجهة، القسم، صباحي/مسائي، المرحلة)
  مع **معاينة حية** للكتاب الرسمي تتحدث مع كل حرف، بصياغة قوالب الكلية الحقيقية
  (وثيقة للمذكر / وثيقة للمؤنث / تأييد للمذكر / تأييد للمؤنث).
- **لوحة الموظف:** جدول الطلبات + بحث وفلتر + إحصائيات، تعديل أي طلب،
  وتحديد دفعة (10 أو 15) وتنزيلها ملف Word واحد جاهز للطبع.
- الطلبات تُحفظ في متصفح المستخدم (localStorage) في هذا النموذج.
- الألوان: كحلي وذهبي — ألوان شعار كلية الوركاء الجامعة الرسمي.

## التشغيل

الموقع ملف واحد `index.html` — افتحه بالمتصفح مباشرة، أو انشره على GitHub Pages:

1. Settings → Pages → Deploy from a branch → Branch: `main` → Save
2. الرابط يصير: `https://<username>.github.io/warkaa-docs-portal/`
